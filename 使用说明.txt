SimuSub 1.6.8 使用说明

安装与首次授权
适用于 Apple Silicon Mac，最低 macOS 13.3。打开 DMG，把 SimuSub 拖到右侧「应用程序」，待复制完成后推出安装盘，从「应用程序」启动。离线识别和翻译模型已包含在安装包内。
在首次引导中申请录制权限；也可从「设置 → 权限 → 屏幕与系统音频录制」进入。若 macOS 列表里没有 SimuSub，点击上方「屏幕与系统音频录制」区域的「＋」，选择 /Applications/SimuSub.app，打开开关，并按系统提示重新打开应用。只剪辑本地视频时可以稍后授权。

推荐配置
日语同传建议使用本地 ASR（语音识别）＋云端翻译。在「模型与服务」保留日语的本地识别模型，点「添加翻译」，填写服务地址、模型 ID 和自己的 API Key，测试连接后点「使用翻译」。这种组合在本机识别音频，把识别出的原文发给所选云服务翻译。需要完全离线时可使用内置翻译模型。

已知局限
日语口语的短语气词有时会在识别或翻译时漏掉。可以先看日语原文：原文里已经缺失的词需要听音补回；原文有而中文遗漏的语气，可以在剪辑工作台修改译文。
快歌的歌词字幕需要人工校对。实测 Demon’s Shot 时，快速演唱段落翻译效果很差；即使使用云端翻译，也建议逐句对照音频。

日中同传
选择声音来源，把源语言设为日语、字幕语言设为简体中文，然后开始同传。默认会使用随应用安装的本地模型。字幕外观可选择日中字体、字号及是否显示原文。
浮窗可拖动缩放，文字自动适应宽高；上方控制暂停、语言、导出和置顶，更多菜单可查看历史、返回主界面或清空。

直播录制
添加并关注主播；双击头像在默认浏览器打开直播间。每行红色按钮控制录制，更多菜单中设置自动录制、监控、开播提醒、暂停或删除主播。
设置 → 录制管理目录、格式、检查间隔及并发数；设置 → 平台筛选平台并选择访客、官网登录或导入 Cookies。

剪辑工作台
独立窗口导入视频。选择选段后，拖动时间轴端点或输入时间；选段决定导出范围；右侧字幕保留整段原视频的时间轴，切换选段后仍可查看和编辑全片字幕。选中字幕行即可编辑日语和中文；时钟按钮编辑字幕时间。
导入按钮直接选择 SRT、VTT、ASS/SSA 文件；按原视频时间导入，自动判断双语行。文字为纯汉字时可在行内修正语言归属。
高光候选可直接勾选后加入选段；样式按钮选择语言和配色。导出菜单支持视频、音频及 TXT/SRT/VTT 字幕。模型生成与核对使用主界面选定的服务；云端实际请求前保留数据传输说明。

设置
外观保留雾蓝、鼠尾草绿、柔紫、奶油黄；可选浅色、深色或跟随系统。应用音频权限在独立「权限」分类处理。模型服务仅在主导航配置。
