# 发布前验收

1. 在 Apple Silicon Mac 上构建签名应用。记录应用版本、构建号和签名身份，运行 `codesign --verify --deep --strict` 检查应用，然后制作并验证只读 DMG。[应用构建](../macos/BUILDING.md) · [安装盘构建](../macos/distribution/README.md)
2. 在独立用户环境中双击 DMG，从 Finder 把 SimuSub 拖进「应用程序」。推出 DMG，从「应用程序」打开；按首次引导申请录制权限。首次拒绝后也应能从设置恢复。用测试播放器播放语音，确认授权后的应用能采到声音并显示双语字幕。
3. 在剪辑工作台导入视频，生成全片字幕。选取其中一分钟，核对整段视频的字幕仍可编辑。试一次手动补字幕、修改译文、调整字幕颜色与大小、保存重开，再导出选段。核对成片的时长、音轨、字幕样式和时间码。
4. 以同一签名身份覆盖安装上一版，检查旧配置、模型及项目，再播放测试音频。若调整了界面，还应在窗口和全屏状态下检查被改动的控件。在独立偏好与临时目录内运行自动检查，保留测试输出。
5. 发布前逐项核对文件名及 SHA-256。验证完整 DMG 能下载和挂载，两个 GitHub 分卷合并后的 SHA-256 与完整 DMG 一致。将成品和必要证据归档后再清理本地旧构建。

## 签名包自动回归

从仓库根目录执行，`APP` 指向已签名的应用，`CORPUS` 指向包含至少六个可读音频样本的 JSON 语料，`RUN` 指向新的测试输出目录。检查会优先复用应用所带模型，也支持本机已有的验证模型目录。

```sh
python3 macos/scripts/check-release-package.py "$APP" "$CORPUS" "$RUN"
```

测试工具写入签名、自检、实际模型的双语字幕和剪辑回归结果。系统录制授权和 Finder 安装需要在图形界面单独验证。自动回归所用的合成视频及来源见[测试素材](../macos/Fixtures/README.md)。
